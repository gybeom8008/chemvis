chemvis는 화학을 모르는 사람이 화학 반응을 보자마자 알게 그리는 웹앱이다. 튜토리얼 25장(src/tutorial/chapters.ts), 예시 장면 다섯(src/tutorial/examples.ts), AI가 대본을 쓸 때 읽는 안내서(public/ai-guide.md), 교육 과정 기획(docs/plan/curriculum.md)이 있다. 이 글들은 클라우드 세션의 Claude가 썼고, 화학 전문가의 검토를 받은 적이 없다.
</배경>

<일: 화학 내용 검토>
1. 네 자료의 모든 설명 문장(장 소개 intro, 단계 자막 step "...", note 글, tryIt, 안내서의 설명과 예시)과 대본이 그리는 화학(어떤 결합이 끊기고 생기는지, 전하, 생성물, 반응 순서)을 읽고, 화학적으로 틀렸거나 초보자에게 틀린 인상을 주는 곳을 모두 찾아라.
   - 예: 반응 기구를 실제와 다르게 그리면서 설명은 실제 기구처럼 말하는 곳, 평형을 한쪽으로 완결되는 것처럼 말하는 곳, 수치(에너지 등)가 근거 없이 적힌 곳, 용어를 잘못 쓴 곳, 생물학 예시(미토콘드리아, ATP, 뿌리털)를 지나치게 단순화해 틀린 곳.
   - 단순화 자체는 괜찮다. 단순화가 틀린 사실을 가르치게 되는 곳만 지적하라.
2. 지적마다: 위치(파일:줄), 지금 문장(짧게 인용), 무엇이 왜 틀렸는지(출처가 필요하면 출처 URL), 고친 문장(해요체, 번역 투 없이, 화학을 모르는 사람이 읽고 바로 아는 말. 지금 문장의 길이와 비슷하게), 대본도 고쳐야 하면 고칠 대본 줄.
3. 심각도를 셋으로 나눠라: 틀림(사실과 다름) / 오해 소지(맞지만 틀리게 읽힘) / 다듬기(사소함). 틀림부터 적는다.
4. 대본이 그리는 화학이 엔진 한계 때문에 틀릴 수밖에 없는 곳은 따로 모아, 엔진에 무엇이 있어야 바르게 그릴 수 있는지 적어라.
</일>
