## 확인한 것과 판단

확인한 것은 파일 내용과 자동 검사 결과다. 화면을 직접 재생하거나 줄바꿈·읽기 속도를 확인하지는 않았다. 화학 정확성은 앞선 수정 취지를 유지하도록 문장을 대조했으며, 외부 문헌 검증이나 수치 재계산은 하지 않았다.

- 25개 장과 5개 예시에서 step 따옴표 안 글을 제외한 대본 문자열은 시작 시점과 같았다. note도 그대로다.
- 안내서의 실행 대본 두 개도 자막 이외 명령은 같았다.
- src/main.ts에서 전하·분자 사이 인력·산화수·원자 일련번호 설정을 확인했다. 없는 설정을 켜도록 안내하지 않는다.
- src/engine/compile.ts, src/engine/timeline.ts, docs/plan/lab-ui.md, tests/unit/motion.test.ts는 시작 시점과 SHA-256 해시가 같았다.
- 재료 교체 체험은 자막과 어긋날 수 있어 표시 비교·배치·입자 수·관찰 시간 변경으로 바꿨다. 이 체험을 화면에서 직접 실행한 것은 아니다.
- 커밋과 push는 하지 않았다.

Claude는 R02·R03·R07·R08·R09의 표시·분류 오류와 R18의 예시 설명란을 먼저 검토해야 한다. R19는 별도 수업 자료다. 짧아진 자막은 실제 화면에서 읽기 속도와 줄바꿈을 확인해야 한다.
