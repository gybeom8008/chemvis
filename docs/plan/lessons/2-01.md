# 2-01 원자 속

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

원자는 어떻게 전하가 0이 될까요?

## 장면 대본 대신: 그리기 어려운 까닭

현재 원자 공은 원자핵과 안쪽 전자를 나누지 않는다. 바깥 전자 점을 모든 전자로 설명하면 산소에 전자가 여섯 개뿐이라고 오해하게 된다.

## 필요한 엔진 기능

원자핵 안 양성자·중성자와 전체 전자를 구별하는 무대, 입자별 전하 합, 실제 크기 비율과 구별한 확대 표시.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

보기에서 고르기: 양성자와 전자가 같은 수라면 전체 전하는 어떻게 될까요?

- 보기: 0이 돼요 / 양수가 돼요 / 음수가 돼요
- 정답: 0이 돼요
- 해설: 크기가 같은 양전하와 음전하가 서로 상쇄돼요.

## 정리 문장

양성자와 전자 수가 같으면 전하는 0이에요.

## 직접 해 보기

원자 무대가 준비되면 전자 수만 하나 바꾸고 전하 합을 비교해 보세요.

## 검증 메모

대본이 없어 컴파일 대상이 아니다. 관련 코드를 읽고 현재 표시 범위와 수업 목표를 대조한 판단이다. 실행되는 장면을 확인했다는 뜻은 아니다.
