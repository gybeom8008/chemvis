# 2-02 전자 껍질과 원자가 전자

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

결합에 쓰이는 전자는 어디에 있을까요?

## 장면 대본 대신: 그리기 어려운 까닭

지금 보이는 비공유 전자쌍은 전자 껍질이 아니다. 껍질 번호만으로 모든 원소에서 전자가 채워지는 차례를 설명하면 에너지 순서와 맞지 않는다.

## 필요한 엔진 기능

에너지 준위·전자 껍질, 주족 원소 전자배치 자료, 전체 전자와 원자가 전자를 구별하는 표시.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

보기에서 고르기: 주족 원소에서 바깥쪽 전자를 무엇이라고 할까요?

- 보기: 원자가 전자 / 양성자
- 정답: 원자가 전자
- 해설: 원자가 전자는 결합에 주로 참여하는 바깥쪽 전자예요.

## 정리 문장

주족 원소는 바깥 전자가 결합에 주로 참여해요.

## 직접 해 보기

원자 무대가 준비되면 원자가 전자 표시를 껐다 켜 보세요.

## 검증 메모

대본이 없어 컴파일 대상이 아니다. 관련 코드를 읽고 현재 표시 범위와 수업 목표를 대조한 판단이다. 실행되는 장면을 확인했다는 뜻은 아니다.
