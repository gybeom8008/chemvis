# 2-03 주기율표 읽기

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

주기율표에서 같은 줄은 무엇이 비슷할까요?

## 장면 대본 대신: 그리기 어려운 까닭

주기율표와 원자 전자배치를 연결하는 화면이 없다. 분자 점 개수만 세면 이온과 중성 원자도 구별하기 어렵고, 헬륨 예외를 설명할 수 없다.

## 필요한 엔진 기능

족·주기 선택, 주족 원소 전자배치 연동, 헬륨 예외 표시.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

- 정답: 두 개예요
- 해설: 헬륨은 첫 전자 껍질에 전자가 두 개 있어요.

## 정리 문장

같은 족 주족 원소는 바깥 전자 수가 대체로 같아요.

## 직접 해 보기

주기율표가 준비되면 헬륨과 네온을 번갈아 골라 바깥 전자 수를 세어 보세요.

## 검증 메모

대본이 없어 컴파일 대상이 아니다. 관련 코드를 읽고 현재 표시 범위와 수업 목표를 대조한 판단이다. 실행되는 장면을 확인했다는 뜻은 아니다.
