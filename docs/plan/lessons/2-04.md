# 2-04 옥텟 규칙

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

원자는 모두 전자 여덟 개를 채울까요?

## 장면 대본 대신: 그리기 어려운 까닭

atoms는 물에서 옥텟을 세지만 비활성 기체 전자배치와 예외를 다루지 않는다. 일부 분자만으로 모든 원자가 여덟 개를 채우려고 반응한다고 가르치지 않는다.

## 필요한 엔진 기능

원자 무대, H·He와 전자 부족 분자·라디칼·전이금속 비교 자료, 옥텟을 반응 원인으로 오해하지 않는 안내.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

보기에서 고르기: 수소도 둘레에 전자가 여덟 개 있어야 할까요?

- 보기: 두 개로 채워져요 / 여덟 개가 필요해요
- 정답: 두 개로 채워져요
- 해설: 수소에는 첫 전자 껍질만 있어요.

## 정리 문장

옥텟 규칙은 예외가 있는 전자 수 규칙이에요.

## 직접 해 보기

비교 화면이 준비되면 수소와 산소 둘레 전자 수를 각각 세어 보세요.

## 검증 메모

대본이 없어 컴파일 대상이 아니다. 관련 코드를 읽고 현재 표시 범위와 수업 목표를 대조한 판단이다. 실행되는 장면을 확인했다는 뜻은 아니다.
