# 3-01 이온 결합

상태: 초안.

## 질문

소금 결정은 무엇이 서로 붙어 있을까요?

## 도입

전자 수를 세려고 Na 원자와 Cl 원자부터 그리며, 실제 소금 생성 경로와 입체 격자는 줄여 보여 줘요.

## 장면 대본

```text
scene "이온 결합"
stage gas
mol n1 = Na at 280,240
mol c1 = Cl· at 500,240
mol n2 = Na at 280,420
mol c2 = Cl· at 500,420
step "Na 원자와 Cl 원자가 두 개씩 있어요"
  note n1 "나트륨 원자"
  note c1 "염소 원자"
step "첫 Na 원자와 Cl 원자가 가까워져요"
  approach n1.Na c1.Cl
step "Na는 전자 하나를 내주고 Cl은 전자 하나를 받아요"
  hop n1.Na -> c1.Cl
step "다음 두 원자도 가까워져요"
  approach n2.Na c2.Cl
step "다음 Na 원자도 Cl 원자에 전자 하나를 내줘요"
  hop n2.Na -> c2.Cl
step "서로 반대 전하를 띤 이온들이 모여 결정을 이뤄요"
  precipitate using n1 c1 as salt
step "다음 두 이온도 붙으며 Na+와 Cl-가 번갈아 놓여요"
  precipitate using n2 c2 onto salt
```

## 예측 질문

3단계 전 · 보기에서 고르기: 전자를 받은 Cl은 어떤 전하를 띨까요?

- 보기: -1 / 0 / +1
- 정답: -1
- 해설: 음전하를 띤 전자 하나가 더해져요.

## 정리 문장

이온 결합은 반대 전하를 띤 이온 사이 인력이에요.

## 직접 해 보기

원자 번호 표시를 켜고 결정이 생기기 전후에 같은 원자를 찾아보세요.

## 필요한 엔진 기능

없음.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 7단계, 오류 0건, 경고 0건.

단독 원자에서 출발하는 전자 수 도식이다. 금속 Na와 Cl2가 반응하는 실제 경로로 사용하지 않는다. 물을 배경에 넣지 않았다. precipitate는 여기서 결정 배치 동작으로만 쓰며 기체 속 침전 반응이라고 설명하지 않는다. 생성물을 독립 NaCl 분자 두 개로 부르지 않는다. 원자가 멀리 떨어진 상태에서 자발적으로 전자를 내놓는다는 주장도 하지 않는다.

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
