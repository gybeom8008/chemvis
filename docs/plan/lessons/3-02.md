# 3-02 공유 결합

상태: 초안.

## 질문

수소 원자 둘은 어떻게 이어질까요?

## 도입

따로 준비한 수소 원자에서 결합 전후를 비교하며, 결합 때 나오는 에너지가 빠져나가는 과정은 생략해요.

## 장면 대본

```text
scene "공유 결합"
stage gas
mol a = H· at 340,310
mol b = H· at 620,310
step "수소 원자마다 전자가 하나씩 있어요"
  note a.H "전자 하나"
  note b.H "전자 하나"
step "두 수소 원자가 가까워져요"
  approach a.H b.H
step "두 원자는 전자 하나씩을 내어 전자쌍을 함께 써요"
  hop a.H -> a.H~b.H
  hop b.H -> a.H~b.H
step "두 수소 원자가 공유 결합으로 이어졌어요"
  note a.H~b.H "공유 결합"
```

## 예측 질문

3단계 전 · 세기: 두 원자가 함께 쓸 전자는 모두 몇 개일까요?

- 정답: 2
- 해설: 각 원자에서 하나씩 내어 전자쌍 하나가 돼요.

## 정리 문장

공유 결합에서는 두 원자가 전자쌍을 함께 써요.

## 직접 해 보기

원자 번호 표시를 켜고 결합 전후에 수소 원자 두 개를 찾아보세요.

## 필요한 엔진 기능

없음.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 4단계, 오류 0건, 경고 0건.

두 hop은 같은 단계에서 실행한다. 한 전자만 든 결합을 안정한 중간 상태처럼 만들지 않는다. 고립된 두 원자 충돌만으로 안정한 H2 생성이 완료된다는 속도·에너지 주장은 하지 않는다.

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
