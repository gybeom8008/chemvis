# 3-05 전기 음성도와 극성

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

결합한 두 원자는 전자를 똑같이 당길까요?

## 장면 대본 대신: 그리기 어려운 까닭

lens charge는 형식 전하를 표시한다. HCl에 형식 전하 +1과 -1을 붙이면 중성 분자와 떨어진 이온을 혼동한다. forces의 δ 메모나 비교 화면의 빛만으로 결합 전자 분포가 치우치는 과정을 확인할 수 없다. 정적인 δ 메모는 가능하지만 수업 목표를 모두 충족하지 못한다.

## 필요한 엔진 기능

형식 전하와 구별한 δ+/δ−, 결합 전자 분포·결합 쌍극자와 범례.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

보기에서 고르기: HCl에서 결합 전자를 더 세게 당기는 쪽은 어디일까요?

- 보기: Cl / H
- 정답: Cl
- 해설: Cl은 H보다 전기 음성도가 커요.

## 정리 문장

결합 전자가 한쪽에 치우치면 결합에 극성이 생겨요.

## 직접 해 보기

부분 전하 표시가 준비되면 형식 전하 표시와 번갈아 켜 보세요.

## 검증 메모
