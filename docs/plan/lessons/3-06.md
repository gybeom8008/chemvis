# 3-06 분자의 모양

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

분자는 종이 위 그림처럼 납작할까요?

## 장면 대본 대신: 그리기 어려운 까닭

geometry.ts는 전자쌍 배치를 평면에 펼친다. CH4를 십자 모양으로 보여 주며 실제 결합각이나 정사면체를 설명할 수 없다. 전자쌍 반발 모형은 모양을 설명하는 근사이며, 전자쌍이 차례로 자리 잡는 실제 시간 순서가 아니다. [입체 구조와 전자쌍 배치 참고](https://openstax.org/books/chemistry-2e/pages/7-6-molecular-structure-and-polarity).

## 필요한 엔진 기능

정사면체 등 입체 구조·회전, 결합각, 결합 전자쌍과 비공유 전자쌍 배치 구별.

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

## 정리 문장

분자 모양은 전자쌍 배치와 함께 살펴봐요.
