# 3-09 금속 결합

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

금속 안에서 전자는 어디에 있을까요?

## 장면 대본 대신: 그리기 어려운 까닭

compare의 metal과 metal 명령은 조각 전체에 속한 전자를 표시한다. pairs.ts의 seaOf·sea는 점 위치를 정해 조각과 함께 옮기며, 전자 전달 때 점을 이동한다. 조각 안 자유 전자 운동이나 전기장에 따른 흐름은 그리지 않는다. 반응 중 밖으로 나가는 점을 평소 금속 내부 운동으로 설명하지 않는다.

## 필요한 엔진 기능

조각 전체에 퍼진 전자 모형의 내부 운동, 양전하를 띤 원자 부분과 전자 구별, 전기장에 따른 순이동.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

보기에서 고르기: 금속에서 바깥 전자는 한 원자에만 묶여 있을까요?

- 보기: 금속 전체에 퍼져 있어요 / 한 원자에만 있어요
- 정답: 금속 전체에 퍼져 있어요
- 해설: 금속 결합에는 여러 원자에 걸쳐 퍼진 전자가 참여해요.

## 정리 문장

금속 결합에는 조각 전체에 퍼진 전자가 참여해요.

## 직접 해 보기

운동 표시가 준비되면 전기장을 껐다 켜고 전체 전자 흐름을 비교해 보세요.

## 검증 메모

대본이 없어 컴파일 대상이 아니다. 관련 코드를 읽고 현재 표시 범위와 수업 목표를 대조한 판단이다. 실행되는 장면을 확인했다는 뜻은 아니다.
