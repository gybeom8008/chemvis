# 4-03 기체가 물에 녹을 때

상태: 초안.

## 질문

탄산수에서 기체는 어디로 나올까요?

## 도입

물에 녹는 CO2 한 분자만 따라가며, 탄산 생성과 압력에 따른 용해량은 따로 다뤄요.

## 장면 대본

```text
scene "기체가 물에 녹을 때"
stage interface
lens attract off
crowd H2O in water 22
mol c = CO2 at 480,110
step "CO2 분자는 처음에 수면 위에 있어요"
  note c "이산화탄소 분자"
step "CO2 분자가 수면을 지나 물속으로 들어가요"
  gas-in c
step "물속에서도 이 분자는 CO2로 있어요"
  note c "물에 녹은 CO2"
step "녹아 있던 CO2 분자가 다시 공기 중으로 나와요"
  gas-out c
```

## 예측 질문

2단계 전 · 보기에서 고르기: 이 장면에서 CO2가 물에 녹으면 C와 O가 떨어질까요?

- 보기: 분자로 남아요 / 원자로 흩어져요
- 정답: 분자로 남아요
- 해설: 기체가 물에 녹는 것만으로 분자 안 결합이 끊어지지는 않아요.

## 정리 문장

기체 분자도 물에 녹고 다시 공기 중으로 나와요.

## 직접 해 보기

원자 번호 표시를 켜고 수면을 지날 때도 같은 CO2인지 살펴보세요.

## 필요한 엔진 기능

없음.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 4단계, 오류 0건, 경고 0건.

limestone·stalactite에는 해당 동작이 있지만 탄산 반응·석회암 변화까지 이어져 단일 목표에 맞춰 분리했다. CO2 일부가 물과 반응하는 사실을 부정하지 않는다.

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
