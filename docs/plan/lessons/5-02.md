# 5-02 화학 반응식

상태: 초안.

## 질문

반응식 앞 숫자는 무엇을 세는 걸까요?

## 도입

수소와 염소가 반응한 전후만 비교하며, 빛으로 시작하는 실제 연쇄 반응 경로는 여기서 생략해요.

화면에 함께 둘 반응식: H2 + Cl2 → 2 HCl이에요. 분자 수로 세면 1:1:2이고, 반응하는 양도 같은 비로 세어요.

## 장면 대본

```text
scene "화학 반응식"
stage gas
lens numbers on
mol h = H2 at 340,310
mol c = Cl2 at 620,310
step "처음에는 H2 한 분자와 Cl2 한 분자가 있어요"
  note h "H2: 한 분자"
  note c "Cl2: 한 분자"
step "반응 뒤에는 HCl 두 분자가 있어요"
  arrow h.H1~h.H2 -> h.H1~c.Cl1
  arrow c.Cl1~c.Cl2 -> h.H2~c.Cl2
step "H 원자 두 개와 Cl 원자 두 개는 그대로예요"
  note h.H1 "HCl 한 분자에 든 H"
  note h.H2 "다른 HCl 분자에 든 H"
```

## 예측 질문

2단계 전 · 세기: H와 Cl을 하나씩 짝지으면 HCl은 몇 분자일까요?

- 정답: 2
- 해설: H와 Cl이 두 개씩이라 HCl 두 분자가 돼요.

## 정리 문장

반응식 계수는 원자 수를 맞춘 반응 양의 비예요.

## 직접 해 보기

원자 번호 표시를 껐다 켜고 반응 전후에 H와 Cl을 각각 세어 보세요.

## 필요한 엔진 기능

없음.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 3단계, 오류 0건, 경고 0건.

H2 + Cl2 → 2 HCl에서 계수비는 1:1:2다. 같은 반응비를 여러 배로 늘려도 원자 수가 맞는다. 두 arrow는 실제 단일 단계 반응 기구를 뜻하지 않는 전후 비교다. 원자 번호로 대응만 관찰한다. 엔진에는 반응식 계수를 조작하는 전용 화면이 없어 식은 도입 다음 별도 문장으로 제시한다.

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
