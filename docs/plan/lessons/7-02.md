# 7-02 산화수

상태: 초안.

## 질문

산화수는 실제 전하와 같을까요?

## 도입

산화수는 전자를 나눠 세는 규칙으로 구한 수이며, 원자에 실제로 놓인 전하량과는 달라요.

## 장면 대본

```text
scene "산화수"
stage gas
lens charge off
mol a = HCl at 340,300
mol h = H2 at 650,300
step "HCl에서 Cl은 결합 전자를 H보다 더 세게 당겨요"
  note a.Cl "결합 전자를 더 세게 당기는 쪽"
step "결합 전자를 Cl 쪽에 모두 주고 산화수를 세어요"
  lens oxidation on
  note a.H "+1"
  note a.Cl "-1"
step "H2에서는 같은 원소끼리 결합 전자를 반씩 세어요"
  note h.H1 "산화수 0"
  note h.H2 "산화수 0"
step "형식 전하로 세면 HCl의 두 원자는 모두 0이에요"
  lens oxidation off
  lens charge on
  note a.H "형식 전하 0"
  note a.Cl "형식 전하 0"
```

## 예측 질문

3단계 전 · 보기에서 고르기: H2에서 각 H의 산화수는 얼마일까요?

- 보기: 0 / +1 / -1
- 정답: 0
- 해설: 같은 원소끼리는 결합 전자를 반씩 나눠 세어요.

## 정리 문장

산화수는 결합 전자를 정한 규칙대로 나눠 센 값이에요.

## 직접 해 보기

산화수 표시와 전하 표시를 번갈아 켜고 HCl을 비교해 보세요.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 4단계, 오류 0건, 경고 0건.

world.ts의 oxidationState와 lens oxidation은 이미 구현돼 있다. 형식 전하 0도 실제 부분 전하가 없다는 뜻은 아니다. 전자를 실제로 Cl로 옮기는 hop을 쓰지 않았다. [IUPAC 산화수 정의](https://old.goldbook.iupac.org/html/O/O04365_2017.html)의 결합 전자 배분 규칙을 따랐다. 해당 정의는 검색 결과에서 확인했으며 본문 직접 열기는 실패했다.

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
