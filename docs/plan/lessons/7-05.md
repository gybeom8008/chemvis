# 7-05 전기 분해

상태: 그릴 수 없음. 현재 수업 목표를 정확히 보여 주는 대본은 보류한다.

## 질문

전기를 넣어서 반응을 일으킬 수 있을까요?

## 장면 대본 대신: 그리기 어려운 까닭

cell은 왼쪽 산화 전극을 음극, 오른쪽 환원 전극을 양극으로 고정한다. 이를 그대로 전기 분해로 읽으면 전원 연결과 극 부호가 잘못된다. li-battery는 충전 장면이 있지만 흑연 속 Li와 전해질 분해를 단순화하므로 일반 전기 분해 대체 자료로 쓰지 않는다. 모든 전지 반응을 그대로 가역적으로 되돌릴 수 있다는 설명도 피한다.

## 필요한 엔진 기능

외부 직류 전원, 전해 전지 극성, 전극·전해질에 맞는 반쪽 반응, 이온 이동·전자 수지와 기체 생성.

## 예측 질문

아래 문안은 기능을 갖춘 뒤 쓴다. 질문 시점은 구현된 장면에 맞춰 정하며 현재 화면에서 확인한 결과가 아니다.

보기에서 고르기: 전기 분해에서 전자를 받는 전극에서는 어떤 일이 일어날까요?

- 보기: 환원 / 산화
- 정답: 환원
- 해설: 전자를 받는 반응을 환원이라고 해요.

## 정리 문장

전기 분해는 전기 에너지로 반응을 일으켜요.

## 직접 해 보기

전원 기능이 준비되면 전원을 껐다 켜고 전자와 이온 이동을 살펴보세요.

## 검증 메모

대본이 없어 컴파일 대상이 아니다. 관련 코드를 읽고 현재 표시 범위와 수업 목표를 대조한 판단이다. 실행되는 장면을 확인했다는 뜻은 아니다.
