# 8-01 탄소 화합물

상태: 초안.

## 질문

탄소는 어떻게 사슬과 고리를 만들까요?

## 도입

탄소가 이어진 순서를 평면에 펼쳐 보이며, 실제 결합각이나 고리 입체 모양은 나타내지 않아요.

## 장면 대본

```text
scene "탄소 화합물"
stage gas
mol a = smiles:CCC at 280,310
mol b = smiles:C1CCCCC1 at 700,310
step "왼쪽 분자는 탄소 세 개가 사슬로 이어져 있어요"
  note a.C2 "사슬 가운데 탄소"
step "가운데 C는 이웃 C 둘과 H 둘에 결합해요"
  note a.C2 "단일 결합 네 개"
step "오른쪽 분자는 탄소 여섯 개가 고리로 이어져 있어요"
  note b "탄소 고리"
step "고리에서도 각 C는 이웃 C 둘과 H 둘에 결합해요"
  note b.C1 "단일 결합 네 개"
```

## 예측 질문

2단계 전 · 세기: 왼쪽 가운데 C에 이어진 단일 결합은 몇 개일까요?

- 정답: 4
- 해설: C 두 개와 H 두 개에 하나씩 이어져 있어요.

## 정리 문장

탄소는 결합을 네 개 이루며 사슬과 고리를 만들어요.

## 직접 해 보기

원자 번호 표시를 켜고 탄소만 차례로 짚어 사슬과 고리를 따라가 보세요.

## 필요한 엔진 기능

없음.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 4단계, 오류 0건, 경고 0건.

프로페인과 사이클로헥세인 구조를 비교한다. 이 수업의 네 결합은 모두 단일 결합이다. 다른 탄소 화합물에서는 결합 차수를 합해 세며 무조건 이웃 원자가 네 개라는 뜻이 아니다. 고리가 평면이라는 결론을 내리지 않는다.

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
