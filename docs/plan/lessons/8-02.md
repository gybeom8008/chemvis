# 8-02 작용기

상태: 초안.

## 질문

분자에서 자주 반응하는 부분을 찾을까요?

## 도입

작용기 세 가지를 대표 구조로 찾고, 성질은 분자 전체와 주변 조건도 함께 보아야 해요.

## 장면 대본

```text
scene "작용기"
stage gas
mol e = C2H5OH at 240,310
mol a = CH3COOH at 510,310
mol n = smiles:CN at 780,310
step "에탄올에는 OH가 붙어 있어요"
  note e.O "하이드록시기(-OH)"
step "아세트산에는 C=O와 OH가 한 C에 붙어 있어요"
  note a.C2 "카복실기(-COOH)"
step "메틸아민에는 NH2가 붙어 있어요"
  note n.N "아미노기(-NH2)"
step "카복실기 안 OH는 에탄올의 OH와 주변 구조가 달라요"
  note a.O2 "옆 C에 C=O가 있어요"
  note e.O "옆 C에 C=O가 없어요"
```

## 예측 질문

4단계 전 · 보기에서 고르기: OH가 보이면 두 분자의 성질은 모두 같을까요?

- 보기: 주변 구조도 봐야 해요 / 모두 같아요
- 정답: 주변 구조도 봐야 해요
- 해설: OH가 어떤 원자 무리에 이어졌는지도 성질에 영향을 줘요.

## 정리 문장

작용기는 분자 전체와 주변 조건을 함께 살펴봐요.

## 직접 해 보기

원자 번호 표시를 켜고 두 OH가 붙은 탄소 주변을 비교해 보세요.

## 필요한 엔진 기능

없음.

## 검증과 검토 메모

장면 1: 메모리 컴파일 통과; 4단계, 오류 0건, 경고 0건.

작용기를 찾고 주변 구조 차이를 관찰하는 초안이다. 성질 차이는 6-03의 아세트산 반응과 연결한다. 이 대본만으로 pH·용해도·반응 속도를 측정했다고 설명하지 않는다. NH2와 OH를 독립 이온으로 부르지 않는다. [카복실기 구조 참고](https://openstax.org/books/chemistry-2e/pages/20-3-aldehydes-ketones-carboxylic-acids-and-esters).

브라우저 재생과 화면 배치는 확인하지 않았다. 컴파일 통과는 반응 조건·실제 속도·입체 구조까지 옳다는 뜻이 아니다.
