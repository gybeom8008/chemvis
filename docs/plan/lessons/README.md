## 읽는 법

- 장면 있음: 요청대로 수업 파일에는 기존 장면 ID만 적었다. 제목은 아래 표에 두며 ID는 모두 [chapters.ts](../../../src/tutorial/chapters.ts)에서 찾는다. 질문·정리·체험은 복제하지 않았다. 장면이 존재한다는 뜻이며 출시 가능한 수업이라는 판정은 아니다.
- 초안: 질문·도입·대본·예측 질문·정리·직접 해 보기를 적었다. 단계 번호는 1부터 센다.
- 그릴 수 없음: 현재 기능으로 목표를 정확히 보여 주기 어려워 대본을 보류했다. 분자 그림 자체가 불가능하다는 뜻은 아니다. 관련 장면, 부족한 기능, 사용할 문안을 남겼다.
- 직접 해 보기는 대본 재생기에서 표시나 관찰 조건을 바꾸는 화면 활동이다. 실험실 재료 등록과 수업 재생기 연결은 하지 않았다. 기능이 없는 수업은 구현 뒤 할 활동으로 명시했다.
- 컴파일 통과와 화학적 타당성은 구별한다. 브라우저에서 재생하거나 배치·겹침·움직임을 확인하지 않았다.

## 기존 장면 대조

기준 문서는 [교육 과정](../curriculum.md), [대본 안내서](../../../public/ai-guide.md), [화학 검토 기록](../chem-review.md)이다. 교육 과정의 25/18/8 분류를 그대로 복사하지 않고 현재 대본·명령 처리·그리기 코드를 대조했다.

| 위치 | 확인한 장면 | 수업에 적용한 판단 |
|---|---|---|
| chapters.ts | 25개 장 모두 | ID 파일 29개에서 25개 장을 재사용한다. |
| examples.ts | limestone, stalactite | CO2 출입 동작은 4-03에 맞지만 다른 반응까지 이어져 별도 짧은 초안으로 분리했다. |

| compare.ts | acid, solid, metal | 각각 별도 대본 ACID, SOLID, METAL을 읽고 컴파일했다. 산·침전은 기존 장으로 연결했고, 금속은 3-09 한계 판단과 7-03 초안에 참고했다. |

추가 재사용은 1-01→atoms, 1-02→forces, 2-05→redox, 3-07→forces, 5-01→neutralization이다. 1-04는 기존 forces에 고체·기체 비교가 없어 새 초안을 썼다. 결과적으로 기존 분류보다 장면 있음이 4편 늘었다.

1-01의 atoms는 확대 카메라 효과가 아니라 물 분자 구성을 보여 준다. 2-05의 redox는 Zn→Zn2+와 Cu2+→Cu로 전자를 잃고 얻는 일을 보여 주며 원자 전체 전자배치를 나타내지 않는다. 5-01의 neutralization은 H·O 수가 보존되는 반응 사례로 쓰되, 이온 이름을 새 목표로 추가하지 않는다. 이 세 수업은 기존 장에서 필요한 부분을 골라 설명하는 편집이 필요하다.

## Claude가 검토할 곳

1. 기존 장면을 연결할 때는 intro의 조건과 한계도 함께 옮긴다. ID만 보고 대본을 독립적인 실제 반응 경로로 사용하지 않는다. 1-03 diffusion과 4-06 exchange는 현재 2단계여서 교육 과정의 3~8단계 조건과 다르다. 원본은 수정하지 않았다.
2. energy에는 -75와 barrier 95, redox에는 -212가 남아 있다. 기존 안내서도 물리량·출처 문제를 지적한다. 5-04는 ΔH와 ΔG를 구별하는 목표를 온전히 충족하지 못한다. 2-05·7-01도 기존 에너지 숫자를 학습 근거로 제시하지 않도록 재생기 연결 전에 검토한다.
3. 3-01은 단독 원자 전자 수와 격자 배치 도식, 3-02와 5-02는 결합 전후 비교다. 실제 소금 생성·수소 재결합·할로젠 연쇄 반응 경로로 받아들이지 않게 도입이 충분한지 검토한다. 3-04의 O2는 루이스 전자 수 모형으로 한정한다.
4. 3-06·3-09·5-05·6-05는 각각 입체 모양, 금속 내부 운동, 반응 속도, 정량 pH를 화면으로 답할 기능이 부족하다는 판단이다. 부분 표시만으로 목표를 낮추지 않았다. 2-05는 전자배치 전체가 없어도 목표를 설명할 수 있어 redox 재사용으로 판단했다.
5. 7-03의 무반응은 문헌에 맞춰 정한 결과다. 엔진이 자발성을 판정한 것이 아니다. 8-02는 작용기와 주변 구조를 찾는 첫 초안이며 성질·환경 변화 관찰은 추가 설계가 필요하다. 8-07은 삼량체를 고분자라고 부르지 않고 반복되는 연결과 남은 말단을 보여 준다.
6. 12개 초안의 실제 재생에서 자막 대상·배치·노트 겹침을 확인해야 한다. 특히 7-03의 금속 표면과 8-07의 사슬 확장, 3-01의 결정 배치를 우선 본다. 새 대본의 조건·생략 범위는 각 파일 검토 메모에 적었다.
